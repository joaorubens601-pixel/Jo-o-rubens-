PROJETO - TECH FÁCIL

Projeto simples de Loja Virtual Institucional para a Situação de Aprendizagem 01.

Páginas:
- index.html = página inicial
- produtos.html = produtos da loja
- contato.html = formulário de contato

Pasta:
- css = arquivo de estilo
- img = imagens dos produtos

Para abrir:
1. Abra o arquivo index.html no navegador.
2. Clique nos links do menu para testar as outras páginas.

Para colocar no GitHub:
1. Crie um novo repositório.
2. Envie todos os arquivos e pastas deste projeto.
3. Confira se index.html está na pasta principal.
